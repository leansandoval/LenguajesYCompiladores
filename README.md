<a id="guia-de-instalacion-y-ejecucion"></a>
## 🛠️ Guía de Instalación y Ejecución (Flex / Bison / GCC)

### Prerrequisitos
Para compilar y ejecutar el proyecto del compilador se requiere disponer de:
1. **Flex** (Generador de analizadores léxicos)
2. **Bison** (Generador de analizadores sintácticos)
3. **GCC** (Compilador de C)

---

### Instalación por Sistema Operativo

#### 🪟 Windows
1. Descargar los instaladores de las siguientes fuentes:
   * [Flex en SourceForge](http://gnuwin32.sourceforge.net/packages/flex.htm)
   * [Bison en SourceForge](http://gnuwin32.sourceforge.net/packages/bison.htm)
   * [MinGW / GCC](https://sourceforge.net/projects/mingw/files/)
2. Seguir el [instructivo de instalación](https://issuu.com/lilianachisaguano/docs/instalacion_de_flex__bison_y_mingw).
3. **Configuración de Variables de Entorno**:
   * Para `flex` y `bison`, instalar en `C:\GnuWin32` y agregar `C:\GnuWin32\bin` a la variable del sistema `Path`.
   * Para `gcc`, agregar la ruta bin de MinGW (ej: `C:\MinGW\bin`) a la variable `Path`.

#### 🐧 Ubuntu / Debian
Ejecutar en la terminal:
```bash
sudo apt-get update
sudo apt-get upgrade
sudo apt-get install flex
sudo apt-get install bison
sudo apt-get install gcc
```

Verificar la instalación:
```bash
which flex
which bison
which gcc
```

#### 🍏 macOS
Ejecutar en la terminal utilizando Homebrew:
```bash
brew install flex
brew install bison
brew install gcc
```

Verificar la instalación:
```bash
which flex
which bison
which gcc
```

---

### 🚀 Ejecución del Compilador

* **Windows**: Ejecutar el script `run.bat`
* **Linux / macOS**: Ejecutar el script `run.sh`

<a id="herramientas-utilizadas"></a>
## 🛠️ Herramientas Utilizadas
* **C (GCC)**: Lenguaje principal utilizado para la implementación de las acciones semánticas y estructuras de datos del compilador.
* **Flex (Fast Lexical Analyzer)**: Herramienta empleada para la generación del analizador léxico a partir de expresiones regulares.
* **Bison (GNU Parser Generator)**: Generador de analizadores sintácticos LALR(1) que procesa las reglas gramaticales en BNF.
* **Visual Studio Code / GCC**: Entorno de desarrollo e infraestructura de compilación utilizada para el desarrollo del proyecto.
